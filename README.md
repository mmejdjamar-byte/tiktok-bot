# بوت تيليجرام لتحميل مقاطع تيك توك بدون علامة مائية

## طريقة التشغيل

### 1. إنشاء البوت في تيليجرام
1. افتح تيليجرام وابحث عن `@BotFather`.
2. أرسل له `/newbot` واتبع التعليمات (اسم البوت + username).
3. راح يعطيك **توكن** شكله مثل: `123456789:ABCdefGhIJKlmNoPQRstuVWXyz`.

### 2. تجهيز الجهاز
```bash
cd tiktok_bot
pip install -r requirements.txt
```

تأكد إن `ffmpeg` مثبت:
- **ويندوز**: نزّل من https://ffmpeg.org/download.html وأضفه لمتغير PATH
- **لينكس (Ubuntu/Debian)**: `sudo apt install ffmpeg`
- **ماك**: `brew install ffmpeg`

### 3. ضبط التوكن
اختر إحدى الطريقتين:

**أ) متغير بيئة (الأفضل أمنيًا):**
```bash
# لينكس/ماك
export BOT_TOKEN="التوكن_حقك"

# ويندوز (PowerShell)
$env:BOT_TOKEN="التوكن_حقك"
```

**ب) مباشرة داخل الكود:**
افتح `bot.py` وعدّل السطر:
```python
BOT_TOKEN = os.environ.get("BOT_TOKEN", "ضع_توكن_البوت_هنا")
```
وغيّر `"ضع_توكن_البوت_هنا"` بتوكنك.

### 4. تشغيل البوت
```bash
python bot.py
```

### 5. الاستخدام
افتح البوت في تيليجرام، أرسل `/start`، ثم أرسل رابط أي مقطع تيك توك — راح يرجع لك الفيديو بدون العلامة المائية.

## ملاحظات مهمة

- **الحد الأقصى للحجم**: البوتات العادية في تيليجرام تقدر ترفع ملفات حتى ~50 ميجا فقط. لو احتجت ملفات أكبر، تحتاج تشغّل Local Bot API Server (خارج نطاق هذا الشرح البسيط).
- **الاستخدام المسؤول**: احترم حقوق الملكية الفكرية وشروط استخدام تيك توك. حمّل فقط المقاطع اللي تملك حق تحميلها أو المتاحة للعامة للاستخدام الشخصي، وتجنب إعادة نشرها تجاريًا دون إذن صاحب المحتوى.
- لو تيك توك غيّر بنيتهم الداخلية مستقبلًا وتوقف yt-dlp عن العمل معهم، فقط حدّث المكتبة:
  ```bash
  pip install -U yt-dlp
  ```

## نشر البوت بشكل دائم (اختياري)
لتشغيل البوت 24/7 بدون إبقاء جهازك مفتوح، تقدر تستضيفه على:
- خادم VPS بسيط (مثل Ubuntu server) مع `systemd` أو `screen`/`tmux`
- خدمات مثل Railway أو Render (لهما خطط مجانية محدودة)
